# 批量图像质量门

## 逐张验收

| 检查项 | 通过标准 |
|---|---|
| 目的 | 对应规划中的唯一画面目的 |
| 主体 | 人物、产品、角色和环境正确 |
| 比例 | 与该项规划一致 |
| 文字 | 标题和短标签准确、完整、可读 |
| 一致性 | 品牌色、字体气质、网格、角色和光线连续 |
| 清洁度 | 无水印、乱码、随机品牌、畸形或无关元素 |
| 文件 | 真实存在且可以打开 |

任一项失败时标记“待返工”，只重新生成或处理该项。

## 连续长图接缝验收

接缝验收必须查看 1:1 局部预览，不能只看缩略长图或联系表。

| 检查项 | 通过标准 |
|---|---|
| 水平切线 | 接缝处没有一眼可见的直线、断层或突变边缘 |
| 纹理连续 | 云、雾、火焰、光尘、布带等共享元素的方向、密度和尺度自然延续 |
| 色调连续 | 接缝上下没有突兀的亮度、色温或饱和度跳变 |
| 结构安全 | 标题、人脸、手、产品、建筑硬边等关键结构不落在羽化区 |
| 融合清洁 | 没有双影、重复人物、重复道具、糊成横带或局部透明感 |
| 场景过渡 | 场景或镜头尺度跳变时已有桥接画面，而不是用模糊强行遮盖 |
| 裁切保护 | 统一比例和裁切没有移除已规划的过渡安全区 |
| 文件证据 | 接缝预览真实存在、可打开，并覆盖每一条实际接缝 |

任一接缝失败时，只返工对应分屏边缘、桥接画面或后处理参数。不得因为整张缩略图“看起来还行”而放行。

## 批次验收

- [ ] 计划数量等于实际独立成品数量
- [ ] 每张独立成品都有唯一文件或真实工具结果
- [ ] 合集预览未计入成品数量
- [ ] 后处理产物可以打开，顺序和尺寸正确
- [ ] 连续长图的接缝数量与接缝预览数量一致
- [ ] 每条接缝已按 1:1 局部预览验收，无硬切、重影或明显色调跳变
- [ ] 产物台账状态已更新
- [ ] 最终交付列出所有文件及用途
