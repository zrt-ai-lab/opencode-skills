# 批量图像质量门

## 逐张验收

| 检查项 | 通过标准 |
|---|---|
| 目的 | 对应规划中的唯一画面目的 |
| 主体 | 人物、产品、角色和环境正确 |
| 比例 | 与该项规划一致 |
| 文字 | 标题和短标签准确、完整、可读 |
| 一致性 | 品牌色、字体气质、网格、角色和光线连续 |
| 清洁度 | 无水印、乱码、随机品牌、畸形或无关元素 |
| 文件 | 真实存在且可以打开 |

任一项失败时标记“待返工”，只重新生成或处理该项。

## 批次验收

- [ ] 计划数量等于实际独立成品数量
- [ ] 每张独立成品都有唯一文件或真实工具结果
- [ ] 合集预览未计入成品数量
- [ ] 后处理产物可以打开，顺序和尺寸正确
- [ ] 产物台账状态已更新
- [ ] 最终交付列出所有文件及用途
