# Codex 图像请求模板

先按 `SKILL.md` 判断单图或批量项目。出现“一组、系列、物料、长图、多屏、九宫格”等语义时，不使用单张提示词，改用批量项目模板并等待明确确认。

## 请求信息

| 字段 | 内容 |
|---|---|
| 场景 | {信息图 / 封面 / 长图 / 幻灯片 / 漫画 / 文章插图 / 小红书 / 营销物料} |
| 主题 | {主题或故事} |
| 用途 | {发布载体和目标} |
| 受众 | {目标受众} |
| 数量 | {图片数量} |
| 比例 | {16:9 / 9:16 / 1:1 / 其他} |
| 风格 | {视觉风格、时代、材质、色彩} |
| 文字 | {标题、标签、数字；没有则写无} |
| 参考图 | {本地图片路径或对话图片；没有则写无} |
| 限制 | {禁用元素、版权、品牌或敏感内容} |

## 单张提示词

```text
{统一风格前缀}，{主体}正在{动作}，位于{环境}，包含{关键细节}，
{景别和构图}，{视角和镜头感}，{光线和色彩}，{画幅比例}，
用途是{用途}。画面文字：{准确文字或无}。
排除：水印、乱码、随机文字、无关人物、畸形结构、低清晰度、边框。
```

## 多图规划

| 序号 | 文件名 | 画面目的 | 主体和动作 | 准确文字 | 比例 | 参考关系 | 后处理 |
|---|---|---|---|---|---|---|---|
| 1 | {01-cover.png} | {定调 / 钩子} | {内容} | {文字} | {比例} | 无或指定参考图 | {无} |
| 2 | {02-detail.png} | {展开 / 解释} | {内容} | {文字} | {比例} | 参考第 1 张 | {无} |
| 3 | {03-action.png} | {收束 / 行动} | {内容} | {文字} | {比例} | 参考第 1 张 | {拼接 / 联系表 / 无} |

## 确认闸门

```text
计划数量：{N} 张独立成品（不含预览图）
工程处理：{拼接 / 联系表 / 统一裁切 / 无}
确认状态：未确认
```

必须把完整规划展示给用户。只有收到“确认”“按这个做”“开始生成”等明确确认后，才把状态更新为“已确认”并调用生图工具。
