# 配色协同指南

当图像需要配合文章、幻灯片、视频或公众号素材时，先从目标载体提取主色、辅助色、背景色、文字色和对比度，再写入统一风格前缀。

## 提取顺序

1. 识别已有载体的主色和背景明度。
2. 确定图片主体与背景的对比关系。
3. 为强调信息指定一个主强调色，避免每张图更换强调色。
4. 规定阴影、高光、线条和文字的使用方式。

## 提示词字段

```text
主色：{颜色和用途}
辅助色：{颜色和用途}
背景：{明度、材质和留白}
对比：{低 / 中 / 高}
统一前缀：{每张图都复用的风格描述}
```

多图任务先用首张图验证配色；后续图以真实参考图保持色彩连续，不仅靠文字重复描述。
