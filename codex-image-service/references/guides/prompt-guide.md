# 原生生图提示词指南

## 六段式结构

1. **主体**：谁或什么，外观、材质、数量。
2. **动作**：正在做什么，动作方向和状态。
3. **环境**：地点、时间、天气、背景和空间层次。
4. **镜头**：景别、视角、构图、焦点和留白。
5. **风格**：媒介、时代、质感、光线和调色。
6. **限制**：水印、乱码、随机字母、畸形结构、无关人物等排除项。

## 组织规则

- 先写叙事事实，再写视觉修饰；不要用形容词堆替代画面信息。
- 系列图片复用同一段风格前缀、角色描述、产品描述和色彩基调。
- 文字内容单独列出，短标题优先；画面中需要准确文字时预留高对比留白区。
- 同时提出的要求互相矛盾时，以主题、主体和可读性优先。
- 生成失败时一次只改一个变量：构图、主体、文字、风格或参考图关系。

## 负面约束

默认排除：水印、乱码、随机字母、无意义 logo、重复人物、额外手指、畸形物体、裁切主体、脏乱背景和低清晰度。根据场景追加“禁止多格拼接”“禁止边框”“禁止画面文字”等限制。
