# video-stickfigure

AI 生成粉笔画风格火柴人图片，用于短视频素材制作。

## 核心流程

```
Prompt 组装 → AI 生图（image-service） → HSV 背景统一 → 输出
```

1. 根据场景情绪选择动作描述 + 氛围元素
2. 调用 `image-service` skill 的文生图引擎生成图片
3. 使用 HSV 颜色范围替换，统一背景色为 `#3c5b45`

## 风格方案

| 方案 | 背景色 | 特点 |
|------|--------|------|
| 深墨绿版（推荐） | `#3c5b45` | 黑板粉笔质感，视觉柔和 |
| 纯黑版（备选） | `#000000` | 对比度更高，更简洁 |

## 动作+氛围元素库

| 情绪 | 人物动作 | 氛围元素 |
|------|----------|----------|
| 疲惫 | slumped over | 落叶、阴影、裂地 |
| 成长 | climbing stairs | 阳光、山峰、星星 |
| 承担 | lifting weight | 乌云、雨滴、闪电 |
| 愉悦 | jumping with joy | 纸屑、烟花、闪光 |
| 思考 | sitting cross-legged | 问号、齿轮、灯泡 |

## 质量检查

| 检查项 | 标准 |
|--------|------|
| 文件大小 | 每张 > 50KB（否则重新生图） |
| 背景颜色 | 统一为目标色（必须执行 HSV 处理） |
| 火柴人可见 | 白色线条清晰可辨 |
| 氛围元素 | prompt 中必须包含 2-3 个 |

## 依赖

- `image-service` skill（AI 生图）
- Python 3.10+ / `opencv-python` / `numpy`
