# 发布前检查单

## 文章结构

- [ ] 文件顶部存在 frontmatter，且包含非空 `title`。
- [ ] `cover` 使用相对路径或已确认可访问的网络图片。
- [ ] 正文标题层级清晰，摘要和开头能独立说明文章价值。
- [ ] 代码块、链接、表格和引用在手机宽度下可读。

## 图片与版权

- [ ] 图片使用 jpg/png/gif 等受支持格式。
- [ ] 本地图片路径相对于 Markdown 文件，未写入个人绝对路径。
- [ ] 已确认图片、字体、代码和引用内容具备发布授权。
- [ ] 图片尺寸和文件大小符合当前微信与 wenyan-cli 限制。

## 安全与发布

- [ ] 已运行 `scripts/validate_article.py`。
- [ ] 文章中没有 AppSecret、Token、私钥、内部域名、个人路径或调试日志。
- [ ] 已先运行 `scripts/publish.sh --dry-run`。
- [ ] 草稿提交和正式发布分开确认。
