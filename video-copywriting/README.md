# video-copywriting

短视频爆款文案创作技能，内置方法论、黄金结构和三关校验体系。

## 核心方法论

基于头部账号（王铁柱 286 万赞、渡思人 210 万赞）深度调研，提炼 8 大爆款公式：

| 公式 | 结构 | 适用场景 |
|------|------|----------|
| 痛点+解法 | 问题→方案 | 有明确问题 |
| 反常识 | 打破认知 | 有独特观点 |
| 数字钩子 | N 个要点 | 有多个要点 |
| 对比冲击 | A vs B | 有强对比 |
| 扎心真相 | 揭露现实 | 有深刻洞察 |
| 隐喻比喻 | 用比喻说理 | 抽象主题 |
| 对仗金句 | 押韵对仗 | 金句收藏 |
| 反问触发 | 引发思考 | 社交传播 |

## 黄金结构

```
命令式开头 → 行动链条 → 情感三连 → 反常识金句 → 行动锚点
```

- 开头用"记住"/"真正的"，禁止"你知道吗"
- 正文给行动路径，不解释概念
- 收尾给具体起点"先从 X 开始"，禁止空洞鸡汤

## 三关校验

文案必须通过三关才能进入视频制作：

1. **格式关** — 每句 ≤15 字，无书面语禁用词，用"你/自己"
2. **结构关** — 合格开头词，≥2 个具体动作，具体收尾
3. **逻辑关** — 相邻句满足原因/结果/具体化三关系之一

## 触发场景

- 需要撰写短视频文案
- 需要优化现有文案的爆款潜力
- 翻录对标视频的文案改写
